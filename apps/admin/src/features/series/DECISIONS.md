# シリーズの管理画面

- 一覧と詳細は query の `select` で表示する情報を取り出す。表示に使わない撮影情報だけが変わったときにも、キャッシュには新しい応答を保ち、写真の行は同じ値を使える。
- 一覧には管理用 API が返す画像の数とカバーを使う。各シリーズの画像を取りに行かずに、非公開の画像を含む数と先頭の写真を表示できる。
- シリーズの画像には固定ページの並べ直しと同じ取っ手を使う。置いた時点ですべての ID を送り、応答を待つ間も選んだ順を表示する。並びが競合したときは server から取り直し、管理者が新しい一覧で操作を続けられるようにする。
- 画像の行は、写真・名前・公開状態・その行の操作が変わったときに描き直す。送信中は行の中のボタンを fieldset で止める。並べ直しの取っ手が使う React Aria Components の ButtonContext を行の中身には渡さず、ほかの行を動かすたびに取り外しのボタンまで描き直すのを防ぐ。
- シリーズから画像を外す操作は画像そのものを残す。シリーズを削除すると並びも消えるので、削除の確定前に Dialog でその対象を伝える。

- 編集と公開状態・画像の変更は、同じシリーズへの送信を順番に実行する。詳細を開き直したときも保存中の状態を共有し、次の編集が古い名前・slug・説明から始まるのを防ぐ。
- 画像の追加で `NOT_FOUND` が返ったら、選んだ画像の存在を確かめる。画像の一覧はページに分かれているので、取り直したページに含まれていないという理由だけで選択を外さない。
