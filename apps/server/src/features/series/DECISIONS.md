# 決めたことと理由(series の feature)

- シリーズと画像は多対多で、`series_image` にシリーズごとの位置を持つ。シリーズと画像の ID を合わせた主キーで、同じシリーズに同じ画像が重なるのを防ぐ。
- 公開状態は `publishedAt` の有無で持ち、シリーズは物理削除する。シリーズと画像のどちらを消しても、関係する行は FK の cascade で消える。片方を非公開にしても、もう片方の公開状態と画像の並びを保つ。
- 名前・slug・説明の書き換えでは、シリーズの表のロックを取ってから slug を確かめる。作成や書き換えが重なっても、同じ slug は `SLUG_TAKEN` で断れる。
- 管理用の一覧と取得は、非公開の画像も配信用の URL と一緒に返す。画像の公開状態は、シリーズから外すことなく管理画面で確認できる。
