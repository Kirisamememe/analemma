# 画像のタグ

- 画像とタグの関連は別のテーブルに持つ。タグの名前や並び順を変えても関連を保ち、画像を消したらその画像の関連も消す。タグはどの画像にも付いていないときだけ消せる。
- タグ名は画像のタイトルと同じく200文字までの単一行にする。前後の空白を取り除いて重複を確かめる。大文字と小文字や全角と半角を区別する。
- タグを作るときは末尾に足す。タグを作る・名前を変える・並べ直す・消す操作は、タグのテーブルのロックを取ってから行う。タグがまだ無いときの同時作成や、並べ直すタグの集合を確かめてから更新するまでの追加・削除も競合するため。削除は対象の行もロックし、画像への割り当てが確定してから使用中かを調べる。
- 管理画面に出す枚数には、変換中の画像も数える。サムネイルは配信用の画像がある写真から追加順で新しい2枚を選び、それぞれ最小幅の URL を返す。タグと画像の ID を並べた index を使い、タグごとの枚数と2枚を同じ SQL で取得する。
